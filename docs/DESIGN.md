# 弧光歌词 · 设计与最佳实践

面向小米手环（Vela OS，胶囊屏 192×490）的音乐控制 + 同步歌词 + 歌词本应用。

## 1. 官方约束与事实

- 目标屏幕：小米手环 9 = 192×490，胶囊形，DPR 2.0；手环 10 = 212×520。设计以 192×490 为基准。
- 多屏策略：胶囊屏与圆屏、矩形屏分别设计；弧形/胶囊屏必须留安全区，正文与可点击元素不要贴边。
- 首页 FMP ≤ 2000ms（官方验收线）。
- `list` 超过 10 条应分页/触底加载，单页 item 建议 ≤ 20。
- 页面销毁必须清定时器；与 UI 无关的数据不要放进 ViewModel；文件/存储读取后及时释放。
- 避免大面积 `border-radius` + 背景图叠加、减少动态样式修改和嵌套层级，保证帧率。
- 通信类应用用 `diagnosis()` 判断连接，不要轮询 `getApkStatus()`。
- 界面单位采用 `dp`（固定物理尺寸）配合 `%`/`flex`，避免同一套 `px` 在 192 与 336 屏上比例失真。

## 2. 交互原则

1. **一眼可读**：播放页 3 秒内能回答“在放什么、放到哪、下一句是什么”。
2. **一个主操作**：播放/暂停是唯一强调按钮；其余操作降级为次级。
3. **拇指优先**：控制区放在下半屏；顶部只放状态与退出。
4. **可点区域**：主按钮 ≥ 30dp 高，次级行 ≥ 22dp；相邻按钮留 4dp 以上间隔。
5. **不靠颜色单一传达**：当前歌词同时使用颜色、字号、字重与左侧标记。
6. **没有死路**：未连接、无歌词、空词本都给出明确下一步（重试/演示/词本）。
7. **反馈克制**：只在播放控制与跳转歌词行时短振，不在滚动与自动刷新时振动。
8. **省电**：定时器 500ms，页面隐藏即停止；交给手机端推送状态变化。

## 3. 视觉系统

### 色彩（OLED 友好）

| Token | 值 | 用途 |
| --- | --- | --- |
| `bg` | `#070B10` | 页面底色 |
| `surface` | `#0E151E` | 卡片/按钮底 |
| `surface-2` | `#131D28` | 次级按钮/选中态 |
| `line` | `#1C2836` | 1px 分隔线 |
| `text` | `#EEF4FB` | 主文字 |
| `text-2` | `#9AA9BC` | 次文字（对比度充足） |
| `text-3` | `#63748A` | 仅辅助信息 |
| `accent` | `#6EF3C5` | 主色/当前歌词/播放 |
| `accent-ink` | `#04241C` | 主色上的文字 |
| `warm` | `#FFC46B` | 演示模式/提示 |
| `danger` | `#FF7A7A` | 删除 |

### 字号（dp）

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| Display | 15–17 | 歌名、当前歌词 |
| Title | 12–13 | 页面标题、按钮主文案 |
| Body | 10–11 | 歌手、列表、正文 |
| Caption | 8–9 | 时间、状态、辅助说明 |

最多三级层级；不使用细于 1px 的线。

### 间距与形状

- 间距基数：2 / 4 / 6 / 8 / 12 dp。
- 卡片圆角 10–12dp，胶囊按钮 999dp。
- 页面左右安全边距：胶囊屏 10dp，圆屏通过媒体查询加到 20dp。
- 不使用重阴影；用 1px `line` 和明度差分层。

### 动效

- 只保留一个循环动效：连接/播放状态点 2.4s 呼吸。
- 页面切换、进度更新不做位移动画；歌词换行依靠字号与颜色变化。
- 所有动效在 200ms 内完成，避免长时间动画占帧。

## 4. 页面规格

### 播放页

- 顶部：连接状态胶囊 + 设置入口。
- 中部：唱片视觉（60dp）+ 歌名 + 歌手 + **当前歌词预览 + 下一句**。
- 进度：4dp 轨道 + 时间。
- 控制：上一首 / 播放暂停 / 下一首，单行等分；下方 -10s / +10s。
- 底部：同步歌词 / 歌词本 / 设置 三段入口。
- 点击唱片或歌词预览进入歌词页。

### 同步歌词页

- 顶部：返回 / 标题 / 词本。
- 5 行窗口：当前行 15dp 主色加粗并带 2×18dp 左侧标记；上下文 10dp 次级色。
- 点任意行跳转到该句时间点。
- 底部：`-` / 偏移值 / `+` 单胶囊；点数值归零。
- 无歌词：图标 + 说明 + “获取歌词 / 打开词本”。

### 歌词本

- 列表行：序号/圆点 + 歌名 + 歌手 + 右箭头，高 30dp。
- 超过 12 条分页“显示更多”；管理态二次确认删除。
- 空态提供“载入示例”。

### 阅读器（词本模式）

- 每页 7 行，行高 26dp；时间戳 8dp 辅助色，正文 10dp。
- 当前行主色加粗；点行跳转播放。
- 底部：上一页 / 跟随播放 / 下一页；跟随开启时自动翻到当前句所在页。
- 歌名与页码固定在顶部，避免滚动迷失。

### 设置

- 分组卡片：连接 / 播放 / 关于。
- 开关使用原生 `switch`；连接诊断使用 `diagnosis()`。
- 偏移调整与歌词页共享同一状态。

## 5. 工程最佳实践映射

- `designWidth` 仅作兜底；主要尺寸使用 `dp`，宽度使用 `%` / `flex`。
- 定时器统一在 `player-state` 中管理，页面 `onDestroy` 取消订阅。
- LRC 解析一次缓存，歌词窗口只渲染 5 行，阅读器分页 7 行。
- 词库列表分页加载，避免一次性渲染全部文件。
- 通信层封装 `protocol.js`，兼容字符串 / ArrayBuffer / 对象三种入参。
- 连接状态由 `transport` 统一维护，页面只读快照。
- 所有异步回调捕获异常，避免 JS 错误中断 UI。
- 发布前检查：首页 < 2s、无长日志、无未清理定时器、空态可达。
